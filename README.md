## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn / pnpm

### Installation

```bash
npm install
```

### Development

To start the Vite development server:

```bash
npm run dev
```

### Build

To create an optimized production bundle:

```bash
npm run build
```

### Linting

To run ESLint:

```bash
npm run lint
```
